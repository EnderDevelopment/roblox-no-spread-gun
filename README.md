# No Spread Script for Roblox

This script applies no spread to guns in Roblox, allowing for more accurate shooting. It is designed to work with standard Roblox guns and ensures that the gun's spread property is set to zero, eliminating any inaccuracy in the shots.

## Installation

1. Open Roblox Studio.
2. Create a new script or open an existing one.
3. Copy and paste the contents of `NoSpread.lua` into the script.
4. Save the script.

## Usage

1. Equip a gun in your Roblox game.
2. The script will automatically apply no spread to the gun.
